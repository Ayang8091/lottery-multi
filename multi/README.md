# 🎰 体彩 · 福彩 多游戏智能参考中心

把 7 个热门彩票游戏统一进**一个智能体**，按 **体彩 / 福彩** 两个大类切换：

| 分类 | 游戏 | 类型 | 官方数据源 |
|---|---|---|---|
| 🏆 体彩 | 超级大乐透 | 前区 01-35 选5 + 后区 01-12 选2 | sporttery.cn |
| 🏆 体彩 | 7星彩 | 前6位 0-9 + 末位 0-14 | sporttery.cn |
| 🏆 体彩 | 排列3 | 3 位 0-9 | sporttery.cn |
| 🏆 体彩 | 排列5 | 5 位 0-9 | sporttery.cn |
| 🎁 福彩 | 双色球 | 红球 01-33 选6 + 蓝球 01-16 选1 | cwl.gov.cn |
| 🎁 福彩 | 快乐8 | 01-80 选10 → 选一~选十玩法 | cwl.gov.cn |
| 🎁 福彩 | 福彩3D | 3 位 0-9 | cwl.gov.cn |

每款游戏均提供：**开奖总览 / 数据分析 / 智能出号 / 验票复盘 / 玩法奖金** 五大页签，
内置官方历史数据，支持**结果长图导出**与**手机 / 微信同网访问**。

智能出号按官网投注方式生成：大乐透支持前/后/双区复式、前区胆拖、追加、多倍；双色球支持红/蓝/全复式、红球胆拖；
7星彩支持三种复式；排列3支持直选/组选复式、组合复式、组选胆拖、直选组合胆拖、跨度与和值；排列5支持复式；
快乐8支持选一至选十及复式/胆拖；福彩3D支持单选/组选复式与胆拖，以及 1D/2D、通选、和数、包选、猜大小、猜三同、拖拉机和猜奇偶。
所有胆拖玩法均按号码池计算最大拖码数，并在拖码选择中提供“全拖”。所有复式玩法按游戏实际号码池展示完整选号个数。

## 启动（零依赖，无需 npm install）

```bash
npm run multi          # 仓库根目录 → http://127.0.0.1:8790
# 或在 multi/ 目录内：npm start
```

**免命令直接启动**
- Mac：双击 `multi/start-mac.command`（若提示“无法打开”，右键→打开 一次即可）
- Windows：双击 `multi/start-win.bat`（首次会弹防火墙，勾选“专用网络”允许即可）

## 更新数据（从官方接口拉最新）

```bash
npm run refresh --prefix multi        # 抓取 7 游戏全部官方历史 → multi/data/all.json
# 或页面右上角「⟳ 更新数据」仅刷新当前游戏
```

## 测试

```bash
cd multi && npm test
```

## 数据与规则说明

- 历史数据：体彩（webapi.sporttery.cn）大乐透 gameNo=85、七星彩 gameNo=04、排列3 gameNo=35、排列5 gameNo=350133；
  福彩（cwl.gov.cn）双色球 name=ssq、快乐8 name=kl8、3D name=3d。
- 规则核对日期 2026-09-12：大乐透现行 9 奖级、双色球 2026 规则、
  7星彩、排列3/5、快乐8 与福彩3D 均按中国体彩网 / 中国福利彩票官网现行规则。
- 中奖判定均按官方“只兑最高奖级”执行；浮动奖金额以当期公告为准。
